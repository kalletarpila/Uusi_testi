Jokaisen solun kuusi kokonaista polkua:
normal: suora Phase 1 -> Phase 2 -> yksilöllinen tulos -> palaute -> reset.
pairwise: kutsukoodi -> nykyinen TB1 -> navigointi/muutos/palautus -> tulos.
legacy: vanha TB1 -> samat navigoinnit -> TB2 -> kolmen tyypin RATKAISEMATON.
two-way: suora rata -> positiivinen kahden tyypin tasapeli -> TB2 -> RATKAISEMATON,
         kutsuttu osallistuja ja completed-kutsu.
three-way: suora rata -> kolmen tyypin tasapeli -> TB2 -> RATKAISEMATON,
           kutsumaton osallistuja.
decisive: suora rata -> kolmen tyypin tasapeli -> kaikki TB2-kysymykset ->
          yksittäinen ratkaiseva tulostyyppi.

Pelkkää näkymäkokoa ei käytetä kosketuskäytön todisteena. Neljä mobiili/tablet-
näkymää käyttävät hasTouch-, tap- ja havaittuja touchstart-tapahtumia sekä
deviceScaleFactor=2:ta. Chromium/WebKit käyttävät lisäksi isMobile-asetusta;
Firefox ei tue sitä. TB1:n aikana vaihdetaan leveys/korkeus päittäin, tarkistetaan
asettelu ja palataan alkuperäiseen kokoon samassa istunnossa. Tämä on emulointia,
ei fyysisen laitteen, käyttöjärjestelmän näppäimistön tai safe area -alueen testi.
